## AI dev environment (dotclaude)

This project uses the [dotclaude](https://github.com/8408323/dotclaude) plugin as its Claude Code engine:

- **Guardrail hooks** run automatically (secret scan, dangerous-command block, file protection, format-on-save, auto-test). The plugin provides them, so don't copy hook scripts into this repo.
- **Reviewer subagents**: `@security-reviewer`, `@code-reviewer`, `@performance-reviewer`, `@doc-reviewer`, and `@frontend-designer` for UI work.
- **Workflow skills**: `/dotclaude:tdd`, `/dotclaude:ship`, `/dotclaude:debug-fix`, `/dotclaude:pr-review`, `/dotclaude:refactor`, `/dotclaude:explain`, `/dotclaude:test-writer`, `/dotclaude:context-budget`.
- **Base rules** live in `.claude/rules/`. Files marked `dotclaude:managed` are regenerated by `/dotclaude:init`; unmarked files are project-owned.

Run `/dotclaude:init` to (re)scaffold this layer, or `/plugin update dotclaude@dotclaude` to update the engine.
